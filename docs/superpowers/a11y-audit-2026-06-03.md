# Accessibility Audit: DeanDB (Sleeve redesign)

**Standard:** WCAG 2.1 AA · **Date:** 2026-06-03 · **Method:** measured contrast (replicated the app's own `legible()`/`pickOnAccent()` math from `themes.ts`) across **both skins**, plus code review for keyboard/labels/targets/motion. Ratios are computed, not estimated.

## Summary
**Issues:** 13 · **🔴 Critical:** 2 · **🟡 Major:** 5 · **🟢 Minor:** 6
**Headline:** Midnight is in good shape; the failures cluster on the **Paper (default) skin** wherever a **fixed, non-skin-aware color** is used — above all the **Dean Meter score ramp** (`scoreColor()`), which appears on nearly every surface. The skin-aware tokens from Phase 1 (`text-gold`, `--color-on-accent`, per-album accents) **pass** — that machinery works; these findings are the colors that bypass it.

## Findings

### Perceivable (1.4.3 contrast / 1.4.11 non-text)
| # | Issue | WCAG | Severity | Fix |
|---|---|---|---|---|
| 1 | **`scoreColor()` ramp is fixed bright colors used as TEXT** — the Dean Meter number + per-song `Score10`. ## Priority Fixes
1. **🔴 Skin-aware `scoreColor()`** (#1) — highest impact; the Dean Meter is on nearly every screen and is illegible on Paper. ~1 function + 2 call sites + ShareCard untouched.
2. **🔴 Per-skin status/badge colors** (#2) — "Completed" and "Library" badges invisible on Paper.
3. **🟡 Darken `--color-fg-faint`** (#3, #4) — one value per skin; clears a broad swath of small-text failures on both skins.
4. **🟡 Touch targets + input focus/labels** (#6, #7, #8) — keyboard/mobile/AT users; mechanical pass over interactive controls + Login labels.
5. **🟢 Polish** (#5, #9–#12) — input borders, optional motion gating, hero scrim, Avatar alt.

## What already passes (the Phase-1 machinery works)
`--color-fg` & `--color-fg-muted` (both skins) · `text-gold` clamped accent · `--color-on-accent` fills (the 5b fix: 6.22 / 12.88) · per-album/-artist accents (clamp to ≥4.5 by construction) · `StatusBadge "listening"` · all Midnight text except `fg-faint` · color is never the sole signal · reduced-motion on keyframes.
